# Random Number Generator

A simple React application that generates random numbers between 1 and 100 using state management and conditional rendering.

## Features

- Generate random numbers with a button click
- Displays "No number generated yet" initially
- Updates the UI instantly using React state

## Getting Started

1. Install dependencies: `npm install`
2. Run the development server: `npm run dev`
3. Open http://localhost:5174 in your browser
